## 📖 Giới thiệu tổng quan

**Visual Storyteller** là ứng dụng web học thuật hiện đại kết hợp nghệ thuật kể chuyện lịch sử dạng tạp chí số (*historical editorial storytelling*). Dự án số hóa toàn diện và chuẩn mực các nội dung nghiên cứu cốt lõi:

1. **Cơ sở hình thành tư tưởng:** Thực tiễn Việt Nam cuối TK XIX – đầu TK XX, bối cảnh thời đại quốc tế, 3 trụ cột tiền đề tư tưởng - lý luận và nhân tố chủ quan Hồ Chí Minh.
2. **Quá trình phát triển (1911 – 1969):** Tiến trình 5 giai đoạn lịch sử liên tục, 12 mốc son bước ngoặt từ ngày rời Bến Nhà Rồng (1911) đến Tuyên ngôn Độc lập (1945), hai cuộc kháng chiến vĩ đại và Di chúc lịch sử (1969).
3. **Giá trị tư tưởng Hồ Chí Minh:** Tầm vóc di sản đối với dân tộc Việt Nam, phong trào giải phóng thuộc địa thế giới và Nghị quyết vinh danh Danh nhân Văn hóa kiệt xuất của UNESCO năm 1987.
4. **Chuyên đề Luận bàn: Thời thế & Anh hùng:** Luận giải mối quan hệ biện chứng giữa bối cảnh lịch sử và vai trò lãnh tụ (*"Thời thế tạo anh hùng"* và *"Anh hùng tạo thời thế"*), cùng góc nhìn khách quan từ 9 học giả, chính khách quốc tế kèm dẫn nguồn uy tín.
5. **Kho lưu trữ 28 tư liệu ảnh lịch sử chân thực:** Bộ sưu tập 28 bức ảnh tư liệu bảo vật quốc gia và kho lưu trữ Wikimedia Commons, phân bổ đều theo 7 danh mục chuyên đề, hỗ trợ phóng to chi tiết (Lightbox), chú thích lịch sử sâu sắc và liên kết bài viết Wikipedia tiếng Việt đã kiểm chứng 100% HTTP 200.

## ✨ Tính năng nổi bật

* **Giao diện học thuật trang nhã (Historical Editorial Aesthetic):** Hệ thống tông màu vàng giấy dó (*parchment*), đỏ gạch trầm và vàng kim, tối ưu trải nghiệm đọc nghiên cứu lâu dài không mỏi mắt.
* **Hệ thống điều hướng chuẩn mực:** Các đường dẫn ngữ nghĩa (`/co-so-hinh-thanh`, `/qua-trinh-phat-trien`, `/gia-tri-tu-tuong`, `/luan-ban`, `/tu-lieu-anh`), hỗ trợ Drawer Navigation trên máy tính và thanh điều hướng thân thiện trên di động (`/m`).
* **Lọc tư liệu theo thời gian thực & Dynamic Badges:** Bộ lọc danh mục trên trang tư liệu ảnh hiển thị số đếm sống động (`All: 28`, `Địa danh: 6`, `Mốc son: 6`, v.v.), phản hồi tức thì dưới 16ms.
* **Modal Lightbox đa phương tiện:** Nhấp vào bất kỳ bức ảnh nào để mở hộp thoại phóng to độ nét cao, đọc thuyết minh bối cảnh lịch sử, năm chụp, tác giả và nút mở trực tiếp bài viết nguồn gốc trên Wikipedia tiếng Việt.
* **Trích dẫn quốc tế có căn cứ:** 9 nhận định sâu sắc từ các nhà sử học (William J. Duiker, David Halberstam), chính khách (Charles de Gaulle, Fidel Castro) và văn kiện UNESCO 1987.

## 🛡️ Kiến trúc CSDL & Bảo mật máy chủ

### 1. Nạp dữ liệu theo yêu cầu (Dynamic On-Demand Content Engine)
* Tách bạch hoàn toàn giữa View và Data thông qua module `src/lib/content-db.ts`.
* Quản lý trạng thái bằng **TanStack React Query** kết hợp bộ đệm cục bộ **IndexedDB** (`VisualStorytellerContentDB`, schema v6).
* Tự động vô hiệu hóa cache khi có cập nhật dữ liệu mới thông qua cơ chế kiểm tra `DB_VERSION`.

### 2. Bảo mật máy chủ & Chống phá hoại (Security & DDoS Hardening)
Hệ thống SSR được tích hợp tầng middleware bảo vệ chủ động tại `src/lib/server-security.ts`:
* **IP Sliding-Window Rate Limiter:** Giới hạn 150 request / 10s cho mỗi IP, ngăn chặn tấn công quét lỗi tự động và bot spam.
* **Payload Bomb Limiter:** Chặn mọi gói tin request body > 256KB (`413 Payload Too Large`), chống cạn kiệt bộ nhớ máy chủ (OOM Crash).
* **Auto Cache Garbage Collection:** Tự động giải phóng bộ nhớ đệm tần suất mỗi 60 giây.
* **Bộ Security Headers tiêu chuẩn OWASP:** `X-Frame-Options: SAMEORIGIN`, `X-Content-Type-Options: nosniff`, `X-XSS-Protection: 1; mode=block`, `Referrer-Policy: strict-origin-when-cross-origin`.

## 🚀 Cài đặt & Vận hành

### 1. Yêu cầu hệ thống
* **Node.js**: Phiên bản 18.x, 20.x hoặc mới hơn.
* **npm** (hoặc `pnpm` / `yarn`).

### 2. Cài đặt mã nguồn
```bash
git clone https://github.com/azizu1012/visual-storyteller.git
cd visual-storyteller
npm install
```

### 3. Chạy môi trường phát triển (Development)
```bash
npm run dev
```
Mở trình duyệt truy cập: [http://localhost:5173](http://localhost:5173) hoặc [http://localhost:5173/tu-lieu-anh](http://localhost:5173/tu-lieu-anh).

### 4. Thực thi kiểm thử tự động (Automated Testing)
```bash
npm test -- --run
```
*Hệ thống sẽ chạy toàn bộ 15 bài kiểm thử kiểm tra tính vẹn toàn của 28 tư liệu ảnh, tính chính xác của dữ liệu Phố Hàng Buồm, các danh mục và logic điều hướng.*

### 5. Kiểm tra kiểu dữ liệu (TypeScript Typecheck)
```bash
npx tsc --noEmit
```

### 6. Đóng gói sản phẩm (Production Build)
```bash
npm run build
```
Bản build chuẩn tối ưu sẽ được xuất ra thư mục `.output/` sẵn sàng chạy với lệnh:
```bash
node .output/server/index.mjs
```
